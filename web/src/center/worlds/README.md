# Orbix procedural worlds

These worlds are original Three.js geometry composed in React Three Fiber. They use no downloaded models, remote fonts, texture packs, physics service or blockchain reads. Small canvas-generated glyph textures are owned by `FaceLabel` and disposed when replaced/unmounted. R3F owns the renderer and primitive resources.

`GameWorld` is the lightweight entry; it lazily imports the renderer. The parent supplies server public state and meaningful DOM controls. Optional callbacks carry lane, catch-spawn, aim or attack intent; scenes do not decide collisions, scores, winners or rewards. Loading names the actual stage (renderer module / compact world), with no fabricated progress percentage.

Movement arenas (`arena: true`): `ArenaWorld` renders `bodies`, published `drops`, destructible `crates`, `projectiles`, `boss` and confirmed `events`. Token Catch, Boss Raid and the new `combat-duel` use this presentation; old lane and fixed-strike rooms keep their classic scenes. The renderer caps participants at 50, drops at 120 and projectiles at 80. All 16 parts of all avatar bodies share one instanced draw call; weapons, rings, HP bars and shields are also instanced. Geometry is original and low subdivision. No remote asset downloads delay play.

`ArenaPlay` sends normalized WASD/arrow/touch input at most every 100ms with a strictly increasing `seq`. Zero intent is sent on release and input is cleared on blur, hidden tabs and unmount. Movement authority stays on the server (30Hz stepping / 10Hz snapshots / 250ms input leases). The local visual projection is bounded to 250ms, respects published walls/crates/boss and guard speed, and reconciles toward the next real snapshot; remote avatars interpolate snapshots. A large correction snaps immediately rather than smoothing a teleport through scenery. Clients never submit positions or scores. Pointer targeting sends a facing intent before its queued strike; keyboard strike is immediate. Coins are collected automatically by server distance after landing. DOM actions send attack, interact, push, block and cosmetic equip intents. Characters, shield bubbles, health bars, weapons, falling pickups and boss windup warning disks derive from real state.

Arena `nowMs`, drop/event times and projectile expiry use elapsed milliseconds. Body cooldowns/shields/stuns/respawns and `serverTimeMs` use epoch milliseconds. Movement projection does not continue past its bound while a snapshot is missing. Server body `inputSeq` seeds the next input number after reconnect. Creature selection is cosmetic and cannot affect HP, speed, hit range or rewards.

State mapping:

- Number Hunt: `digits`, `guessCount[me]`, `claimedTargets`, and `targets` **only when finished**. Mystery cubes stay `?` while targets are private. The fox reacts to server-confirmed guess-count changes.
- Boss Raid: `bossHealth`, `bossHealthMax`, `hits`, `slain`, and up to six actual `players`. Avatar attacks and guardian recoil use confirmed hit/health changes. Optional `teams` accepts address-to-team or team-to-address-list structures. Both side colors are decorative when cooperative mode has no team data.
- Token Catch: `lanes`, `lanesNow[me]`, `scores[me]`, `nowMs`, `catchWindowMs`, and `recent`. Only already-fallen public spawns become gameplay objects. Fall animation and expiry follow the server-configured catch window; no future spawn, score, or collection is fabricated. Lane surfaces call `onLane`; tokens call `onCatch`. Green collection/coral hazard rings react only to confirmed score increases/decreases. The accessible stage also checks eligibility, confirmed lane, expiry and duplicate intent before sending an action.
- Duel: `players`, `phase`, `roundIndex`, `wins`, and completed `history`. Choice totems stay sealed while the current round has no resolved public history. Pending client choices, commit preimages and unrevealed server state are never read.

Presentation: distinct floating puzzle islands, legacy lane/raid worlds, the sealed-choice Rock Paper Scissors Duel, and compact fenced movement playgrounds share soft color lighting. Ref-based joints provide run/action animation. No shadow maps, postprocessing or client physics runs. DPR is bounded to 1–1.5. Hidden browser tabs stop the renderer. Reduced-motion renders classic still worlds on demand and suppresses floating embellishment; arenas keep essential movement frames and suppress pickup spinning. Cameras fit narrow scene widths. Error boundaries, unsupported WebGL and context loss retain the DOM controls and retry.

The world reports no measured FPS claim. Actual browser QA and target-device profiling should inspect draw calls, frame times, cold renderer chunk bytes and context recovery. Essential actions and accessible logs belong to the DOM stage, outside the aria-hidden canvas.

Primary API references: https://r3f.docs.pmnd.rs/api/canvas and https://r3f.docs.pmnd.rs/api/hooks.
